📋 API OVERVIEW

Authentication: All endpoints require Bearer Token

text
Authorization: Bearer YOUR_JWT_TOKEN
Content-Type: application/json
🔘 INVOICE GENERATION (MANUAL TRIGGER)
POST /sync
Purpose: Manual button to generate invoices for all active customers

Payload:

json
{
  "force": false,        // Optional: true to regenerate existing invoices
  "date": "2026-08-04",  // Optional: generate for specific date
  "cycle_type": "weekly", // Optional: "weekly" or "monthly"
  "customer_id": 1       // Optional: generate for specific customer only

📄 INVOICE LIST
GET /
Purpose: Get all invoices with filtering and pagination

Query Parameters:

Parameter	Type	Description
customer_id	integer	Filter by customer
status	string	Draft, Sent, Paid, Partial, Overdue, Cancelled
cycle_type	string	weekly, monthly
start_date	date	YYYY-MM-DD
end_date	date	YYYY-MM-DD
page	integer	Default: 1
limit	integer	Default: 50
Example Request:

text
GET /invoices?customer_id=1&status=Sent&page=1&limit=10
